# ViewX 1.0 手冊與網頁版功能完整性比對

核對日期：2026-10-12。對象：`InfoSys_ViewGP_Web` 基準提交 `640907d`（package 0.2.0、schemaVersion 1）。這是新增核心元件、系統變數與 Popup／繼承之前的功能稽核快照；後續已實作功能請見 README。

## 範圍與判定方式

來源為附件 `ViewX規劃軟體使用手冊.doc`，不是僅依據需求摘要。已解析 Word OLE 與 53 個文字片段，取得目錄、第一至第七章及附錄 1、2 的正文與表格，並對照前端資料模型、元件、編輯操作、模擬、C# API 與 SQLite 儲存實作。

限制：本次未逐張辨識手冊內嵌截圖。只存在於下拉選單／截圖而未在正文說明的品牌、圖形種類與功能，不列為已證實規格。手冊本身有章號交叉引用錯誤，例如第六章文字把多國語言稱為第七章；本報告依目錄與實際節標題定位。3-4.4 提及「附錄3」，但附件目錄與擷取正文只有附錄1、2；日期格式以該節表3-4為依據。

狀態：**已實作**表示核對的基本行為存在；**部分**表示存在功能子集或替代流程；**缺失**表示目前模型、介面及執行路徑未提供；**待查證**表示附件文字不足以支持原始規格宣稱。已實作不代表通過原版硬體相容性認證。

本次是功能稽核與規劃，沒有新增產品功能。未定義需求原子項目及權重前，不提供總體百分比，也不以「14 種元件」推算「50% 原版覆蓋率」。

## 結論與原清單修正

網頁版已具備可用的畫面編輯、型別化模擬變數、跨畫面趨勢／警報監看及專案版本保存。最大缺口仍是設備通訊與位址模型、完整畫面結構、專案級語系／安全／警報／音響設定及硬體部署工具。

## 架構落實順序與驗收

建議保留四階段，但**資料來源／系統變數抽象先於依賴它們的元件**；通訊設定的資料結構可提前設計，實際硬體驅動留到第四階段。

| 階段 | 交付 | 依賴與最低驗收 |
| --- | --- | --- |
| P1 核心資料與常用元件 | 變數來源分internal／system／controller；系統變數映射；RTC、多態燈、點動、返回、刻度、表格；數值補零／hex | 舊schema-v1專案可開啟並保存；系統唯讀拒寫；RTC／画面狀態由runtime產生；點動在pointerup/cancel、失焦、切頁、停止時歸零；返回歷程有邊界；新增設定前後端驗證一致 |
| P2 畫面與語系 | 群組、數字ID、screen type、parentScreenId、開機／初始流程、Popup結果；語言與每元件翻譯 | 拒絕循環繼承；父修改同步、子不能改父元件；刪除引用有保護；Popup確認執行一次、取消不寫值；語言透過N65342切換並明確測試缺譯文政策 |
| P3 警報／安全／鍵盤／音響 | 全域警報區與事件儲存；Word遮罩／邊緣／週期／群組；8密碼3權限；觸控鍵盤；頻率序列聲音；管理樹 | 位元0～15與遮罩逐位測試；多警報排序；持久化歷史重啟仍可查；權限由共用動作入口檢查，隱藏UI不等於授權；輸入buffer取消不寫值；音響重複與靜音可驗證 |
| P4 真實設備與相容工具 | 埠／協定／控制器UI、C#通訊服務、首個可驗證驅動、連線模擬；機型能力與部署流程 | 設備ID／站號唯一；重試／逾時／資料品質與斷線狀態；實機讀寫與站號隔離；每驅動獨立驗收；HMI二進制與OS格式取得後再開發上下傳 |

畫面圖片輸出／列印可獨立於P1～P2並行排程；其他幾何、文字編輯與狀態編輯需維持明確待辦，不能因四階段未列名字就視為完成。跨畫面交叉參考可在P1建立引用掃描，P2擴充繼承引用，P3納入全域規則。

實作接點建議：

- `src/model.ts`：新增專案級模組與来源／畫面模型；提供明確schema遷移，避免靜默丟棄新設定。
- `src/registry/widgetRegistry.ts`、`components/widgets`：新增種類或擴充現有元件；不要為湊數拆分已有圓角功能。
- `hooks/useSimulation.ts`：共用讀寫、系統動作、導航／Popup狀態與授權入口；P1保留本機adapter供測試。
- `hooks/useRuntimeData.ts`、`services/advancedRules.ts`：從元件規則演進為專案級事件源，保留原警報規則相容。
- `services/projectValidation.ts`、`server/ProjectValidator.cs`及專用驗證器：同步支援新欄位、唯讀限制與引用驗證。
- `server/Program.cs`：現在只提供專案／版本API，需另加通訊生命週期與runtime事件介面；已有C#後端，不必重建。
- `server/ProjectStore.cs`：現在保存的是專案快照與版本；操作事件／趨勢／警報歷史應採專用表與留存政策。版本歷史不能當警報歷史。

WebSerial可用於可支援瀏覽器與使用者授權的串列裝置；Modbus TCP可由現有C#服務承接。瀏覽器前端不能直接以一般fetch開任意TCP串流。品牌驅動清單、設備文件及實機測試對象須先取得；配置介面完成不代表通訊能力完成。
