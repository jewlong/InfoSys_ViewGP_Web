## 2. 產品背景與現狀

InfoSys_ViewGP_Web 是一個 Web 畫面規劃／監控設定工具，技術棧為 TypeScript + React 前端、C# + ASP.NET Core 後端、SQLite 儲存。預設離線模擬，亦可由 C# 後端透過 Modbus TCP／COM RTU 讀寫設備，無須舊 `.vxf` 檔或既有 HMI。

現有核心功能（參考 GitHub README）：
- 檔案／編輯／檢視／畫面／元件／排列／變數／執行／說明選單
- 一般畫面與 Popup（對話盒）管理，多層共通母片繼承（最多 16 層巢狀，循環繼承被拒絕）
- 起始畫面設定；18 種元件（時間／日期、多狀態指示燈、刻度、表格等），依「繪圖、靜態、按鈕、顯示、編輯」五類分組
- 畫布拖放、調整尺寸、多選、對齊、群組、圖層、鎖定、格線、復原／重做、框選
- 自動儲存（預設關閉，停止編輯 2 秒後快照至 SQLite；對話框開啟／執行模擬／資料未完成時暫停；無離線草稿復原）
- 版本紀錄與還原、JSON 匯入／匯出、圖片資源管理（共用資源、引用計數）
- 警報歷史（50 筆分頁，服務重啟後仍可讀取，不自動清除）
- Modbus TCP／COM RTU 讀寫、斷線重連、標籤保存

已知限制與痛點（摘自 README 與行為描述）：
1. **無離線草稿復原**：自動儲存未完成前關閉頁面會提醒，但無法復原未儲存的草稿。
2. **自動儲存預設關閉**：使用者容易忘記開啟，導致非預期遺失修改。
3. **對話盒無「確定後才執行」的交易流程**：開啟對話盒只開啟畫面；內部設值／增減按鈕立即執行，關閉動作不寫入變數，無暫存至「確定」才生效的機制。
4. **警報歷史不自動清除**：長期使用須自行規劃資料留存，否則資料庫持續成長。
5. **待送資料僅在記憶體**：無離線磁碟佇列；離頁時會提醒，但無斷線續傳機制。
6. **學習門檻較高**：18 種元件與五類分組、母片繼承、16 層巢狀限制等概念對新手不直覺。
7. **元件庫搜尋與預覽有限**：僅依名稱／類別／英文種類搜尋，缺乏視覺預覽與常用收藏。

## 3. 願景與目標

**願景**：使 InfoSys_ViewGP_Web 成為一個「好上手、不易出錯、可安心長期使用」的人性化畫面規劃工具，降低新手學習門檻，提升現場設備工程師與操作員的設定效率與信心。

**產品目標**：
1. 降低新手完成第一個專案（匯入、配置、離線執行）所需時間。
2. 降低非預期資料遺失與誤操作發生率。
3. 提升元件選取、畫面編輯、對話盒設定的直覺度與效率。
4. 支援長期穩定運行（歷史留存、離線韌性、裝置連線可復原）。

**成功指標（擬，待 AIS-47/AIS-48 細化）**：
- 新手上手時間（首個可執行畫面）較舊版減少 30% 以上
- 常見編輯任務（新增元件、對齊、開啟 Popup）的操作步驟減少 20% 以上
- 使用者回報的「遺失未儲存修改」事件趨近於零
- 離線中斷後重新連線，待送資料可自動續傳

## 4. 目標使用者

| 使用者角色 | 主要需求 | 使用情境 |
|---|---|---|
| 廠務／設備工程師 | 建立與編輯設備監控畫面、設定變數與警報、離線模擬驗證 | 廠房 HMI 畫面規劃 |
| 系統整合商 (SI) | 為客戶客製化畫面、匯入舊專案、Modbus／COM 裝置對接 | 專案交付 |
| 現場操作員 | 監控數值、開啟／關閉對話盒、確認警報 | 生產線現場操作 |
| 維護人員 | 查看警報歷史、版本還原、匯出備份 | 故障排除與備份 |

## 5. 功能需求（多角化功能）

下列需求以「人性化」為切入點，分七大領域。詳細互動流程由 AIS-47 定義，視覺呈現由 AIS-48 定義。

### 5.1 畫布與編輯體驗
- FR-1.1 提供鍵盤快捷鍵（複製／貼上、刪除、全選、撤銷／重做、對齊、群組、鎖定），降低滑鼠依賴。
- FR-1.2 元件拖放時顯示對齊輔助線與吸附預覽，減少誤放。
- FR-1.3 畫布支援縮放、平移、格線開關與尺規顯示。
- FR-1.4 提供「元件導覽／元件樹」列出當前畫面所有元件，可直接選取與重命名。
- FR-1.5 撤銷／重做歷史擴大且跨畫面持續，還原後不清除使用者操作上下文。

### 5.2 元件庫（多角化）
- FR-2.1 元件庫新增「視覺預覽」與「常用／收藏」分類，減少選錯元件。
- FR-2.2 搜尋支援名稱、類別、功能關鍵字與中文別名。
- FR-2.3 新增「最近使用元件」與「快速放置面板」。
- FR-2.4 元件屬性編輯器採用分組與預設值，常用屬性優先顯示。

### 5.3 對話盒（Popup）與交易流程
- FR-3.1 新增「確定／取消」交易流程：對話盒內設值先暫存，點「確定」才寫入變數並套用；「取消」捨棄。
- FR-3.2 支援模態與非模態對話盒切換，並明確標示背景是否可操作。
- FR-3.3 對話盒尺寸與內容依瀏覽器可用空間自動縮放（保留現有行為），並新增最小／最大尺寸限制。
- FR-3.4 巢狀對話盒上限（現 16 層）可於專案設定中調整，並給出清楚的層級提示。

### 5.4 儲存、版本與離線韌性
- FR-4.1 自動儲存預設開啟，閒止偵測時間可設定（預設 2 秒）。
- FR-4.2 新增離線草稿儲存至本機（IndexedDB），離頁或瀏覽器強制終止後下次開啟專案可提醒復原。
- FR-4.3 版本紀錄新增「版本比對（diff）」與「標註重要版本」功能。
- FR-4.4 JSON 匯出／匯出包含專案設定與圖片，並提供「備份至 SQLite 資料庫檔」的一鍵操作。
- FR-4.5 待送資料建立離線磁碟佇列，斷線後自動重試與續傳，離頁時明確提示未同步筆數。

### 5.5 專案管理與範本
- FR-5.1 新增「專案精靈」引導新手完成：專案命名、起始畫面、裝置型別（離線模擬／Modbus TCP／COM RTU）。
- FR-5.2 內建常見畫面範本（泵浦監控、警報面板、趨勢圖），可一鍵匯入。
- FR-5.3 支援專案分類、標籤與搜尋，方便多專案管理。
- FR-5.4 舊 schema-v1 專案無須轉換即可開啟；新專案預設使用新 schema，並向下相容。

### 5.6 監視、警報與資料留存
- FR-6.1 警報歷史支援自動清除策略（依天數或筆數），並可手動匯出。
- FR-6.2 警報查詢新增日期區間、裝置、等級、狀態（發生／確認／解除）組合篩選。
- FR-6.3 趨勢取樣支援量程與警戒色設定，並可跨畫面監看。

### 5.7 設備連線與設定嚮導
- FR-7.1 新增裝置連線設定嚮導（Modbus TCP 位址／埠、COM RTU 連接埠／鮑率／校驗），含連線測試。
- FR-7.2 斷線後自動重連，並以狀態列清楚顯示線上／離線狀態。

### 5.8 無障礙與國際化
- FR-8.1 全鍵盤導航：可用 Tab 與方向鍵操作畫布、元件庫、屬性編輯器。
- FR-8.2 支援高對比模式與字級縮放。
- FR-8.3 介面預設繁體中文，並預留多語言（英文／簡體中文）切換介面。

## 6. 非功能需求

| 類別 | 需求 |
|---|---|
| 效能 | 畫面載入與元件拖放於一般裝置上應在 2 秒內回應；警報歷史查詢（50 筆分頁）在 1 秒內回傳。 |
| 相容性 | 支援 Chrome／Edge 最新版；前端 Node.js 24 以上、後端 .NET 10 SDK。 |
| 安全性 | 專案匯入／匯出需驗證 JSON 結構，防止惡意檔案；HTTP 409 版本衝突保護保留。 |
| 可維護性 | 所有新功能須有對應前端與後端自動化測試（參考既有 npm test 家族）；版本與資料庫遞移需相容舊 schema。 |
| 操作性 | 無須額外安裝舊 HMI 或 `.vxf` 檔即可離線模擬與執行。 |
