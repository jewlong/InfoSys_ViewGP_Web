## 1. 設計命題與範圍

本文件對應 interaction-cooper (Alan Cooper) 職責：**設計使用者流程與導覽、定義目標使用者角色、選擇互動模式、從使用者角度排序功能優先順序**。輸出為後續 AIS-48 (ui-duarte, 視覺設計) 與 AIS-49 (cto-vogels, 技術架構) 的直接輸入。

產品：InfoSys_ViewGP_Web 規劃器人性化升級（TS+React 前端 / C# ASP.NET Core 後端 / SQLite 儲存），Web 畫面規劃與監控設定工具，預設離線模擬，亦可由後端透過 Modbus TCP／COM RTU 讀寫設備。

### 1.1 核心約束 (承接 AIS-46 PRD 與 AIS-45 風險)

1. **必須先解決最高痛點 (MUST)**：FR-4.1 自動儲存預設開啟、FR-4.2 離線草稿復原、FR-3.1 對話盒「確定／取消」交易流程、FR-1.1 鍵盤快捷鍵。這四項直接對應「資料遺失」、「誤操作」兩大風險 (AIS-45)。
2. **零靜默失敗**：自動儲存狀態、裝置線上/離線、待送資料筆數、未儲存變更，必須隨時可見；禁止任何操作結果不給回饋。
3. **不做 (Won't v1)**：跨裝置即時協同編輯、行動 App、自動交易／券商下單、保證獲利表述，均由 AIS-42 商業化階段另評。
4. **效率目標**：核心任務 (新增元件、對齊、開啟 Popup、離線草稿復原) 須在 ≤3 次點擊完成，並使新手首個可執行畫面上手時間較舊版減少 30% 以上 (AIS-46 PRD 成功指標)。
5. **風險節點不可隱藏**：未儲存變更警告、斷線提示、免責聲明，置於首屏與關鍵卡片，不可縮小為微字或可關閉隱藏。

## 2. 目標使用者角色 (Personas)

依 Alan Cooper 方法，以「主要角色 (Primary Persona)」驅動設計決策；次要角色作參考；非設計對象 (Anti-persona) 明確排除，做邊界鎖定。使用者角色與需求直接來自 AIS-46 PRD §4。

### 2.1 主要角色：廠務／設備工程師 (Primary Persona)

- 背景：在工廠現場負責建立與編輯設備監控畫面、設定變數與警報，並以離線模擬驗證後再部署。日常操作畫布拖放、元件屬性編輯、Popup 設定、版本備份。
- 目標：快速完成「匯入 → 配置 → 離線執行」的首個專案；確定修改不會不見；對話框設值不會誤寫入變數；斷線後待送資料能續傳。
- 行為模式：長時間停留在畫布編輯器；頻繁使用撤銷/重做與多選對齊；依賴鍵盤快捷鍵；離開電腦前會確認儲存狀態。
- 痛點：自動儲存預設關閉導致修改遺失；對話盒設值立即生效無法取消；無離線草稿復原；18 種元件與母片繼承概念對新手不直覺。
- 設計含義：以此角色為驗證標準；編輯器須「所見即所得」、狀態隨時可見；誤操作須可還原。

### 2.2 次要角色

| 角色 | 主要需求 | 使用情境 | 設計含義 |
|------|----------|----------|----------|
| 系統整合商 (SI) | 為客戶客製化畫面、匯入舊專案、Modbus／COM 裝置對接 | 專案交付 | 專案精靈與舊 schema-v1 向下相容須順暢；裝置連線嚮導需含連線測試 |
| 現場操作員 | 監控數值、開啟／關閉對話盒、確認警報 | 生產線現場操作 | 對話盒模態與背景可操作性須明確；警報確認動作須簡單防誤 |
| 維護人員 | 查看警報歷史、版本還原、匯出備份 | 故障排除與備份 | 警報歷史篩選與版本比對須直覺；一鍵備份至 SQLite 檔 |

### 2.3 非設計對象 (Anti-personas，明確排除)

- 尋求「穩定獲利／保證報酬」的使用者：與產品紅線與 AIS-42 商業化方向衝突，不納入目標。
- 需桌面軟體或機構級全廠 SCADA (Ignition/WinCC/FactoryTalk) 的使用者：範圍外，Web 零安裝是核心差異化。
- 需跨裝置即時多人協同編輯的使用者：Won't v1，交由商業化階段評估。

## 3. 選擇的互動模式 (Interaction Modes)

| 模式 | 說明 | 適用場景 | 設計要點 |
|------|------|----------|----------|
| **M1 工作區優先 (Workspace-first)** | 登入/開啟專案先呈現「目前狀態」：專案名稱、最近畫面、自動儲存狀態、裝置線上/離線燈、未儲存變更指示、待送筆數。 | 首次進入、每日回流登陸頁 | 解決「不知從何開始」；狀態隨時可見 (Norman 可見性)；禁止靜默狀態。 |
| **M2 直接操作式畫布編輯 (Direct manipulation)** | 元件拖放時顯示對齊輔助線與吸附預覽；支援縮放、平移、格線開關、尺規；多選、對齊、群組、圖層、鎖定、復原/重做。 | 畫面編輯 (FR-1.x) | 降低誤放與滑鼠依賴；拖放預視讓結果可預見；鍵盤與滑雙路徑並行。 |
| **M3 交易式對話盒 (Transactional dialog)** | 對話盒內設值先暫存於本地狀態，點「確定」才寫入變數並套用；「取消」捨絕所有變更；模態/非模態切換並明確標示背景可否操作。 | Popup 設定 (FR-3.x, MUST) | 解決「設值誤寫入變數」痛點；確認按鈕視覺強調，取消為次要；巢狀層級給清楚提示。 |
| **M4 安全優先儲存 (Safe save)** | 自動儲存預設開啟 (預設閒止 2 秒快照至 SQLite)；離線草儲存至 IndexedDB；關閉頁面前若有未儲存變更，以無法忽略的對話提示復原/捨棄。 | 儲存/版本/離線韌性 (FR-4.x, MUST) | 「遺失未儲存修改趨近於零」；離頁提醒不可靜默；離線草稿下次開啟專案時主動提醒復原。 |
| **M5 導覽式上手嚮導 (Guided onboarding)** | 「專案精靈」引導新手完成專案命名、起始畫面、裝置型別 (離線模擬/Modbus TCP/COM RTU)；內建常見畫面範本一鍵匯入；3 個滑動導覽提示。 | 新手首專案 (FR-5.1, FR-5.2) | 降低新手學習門檻；預載常見範本 (泵浦監控、警報面板、趨勢圖) 快速看到成果。 |
| **M6 裝置狀態可見 (Status-visible)** | 全域狀態列顯示線上/離線、斷線後自動重連中、待送資料磁碟佇列筆數、警報等級摘要。 | 裝置連線與警報 (FR-6.x, FR-7.x) | 斷線可感知、續傳可觀看；避免操作員以為設備正常而實際離線。 |
| **M7 無障礙鍵盤導航 (Keyboard-first)** | 全鍵盤導航：Tab 與方向鍵操作畫布、元件庫、屬性編輯器；支援高對比模式與字級縮放；介面預設繁體中文，預留多語言切換。 | 所有頁面 (FR-1.1, FR-8.x) | 無障礙不作為事後補丁，與編輯器核心互動同步設計。 |

## 4. 使用者流程 (User Flows)

以下六條流程涵蓋 AIS-46 PRD Must/Should 需求，並納入上手引導與風險節點。每條流程標註 **（R）風險節點** 與 **（F）使用者回饋節點**。

### F0 首次上手與專案建立 (Project Wizard + Onboarding) — FR-5.1, FR-5.2

1. 使用者進入應用程式 → 首次使用顯示「專案精靈」引導，非空白頁 (M1)。
2. 精靈步驟：專案命名 → 選擇起始畫面範本 (泵浦監控/警報面板/趨勢圖/空白) → 選擇裝置型別 (離線模擬 / Modbus TCP / COM RTU) → 預覽摘要 → 建立專案。
3. 建立完成後顯示 3 個滑動導覽提示：畫布編輯 / 元件庫 / 對話盒與警報位置。
4. (F) 進入主編輯工作區 (M1)，顯示專案狀態、資料新鮮度時間戳、自動儲存預設開啟指示。
5. 引導結束後建議進入今日畫面編輯 (F1 起點) 或元件庫 (F2)。

### F1 畫面編輯與元件放置 (Canvas Editing) — FR-1.1 ~ FR-1.5, FR-2.x

1. 開啟專案後進入畫布編輯器，左側元件庫、右側屬性編輯器、中央畫布 (M2)。
2. 從元件庫拖放元件至畫布 → 拖放途中顯示對齊輔助線與吸附預視 (FR-1.2) → 放開即吸附到格線 (FR-1.3)。
3. (F) 放置成功 → 元件出現在「元件導覽／元件樹」並可直接選取與重命名 (FR-1.4)；狀態列顯示「已放置 X 個元件」與未儲存變更指示 (M4)。
4. 多元件操作：多選、對齊、群組、圖層、鎖定；鍵盤快捷鍵 (複製/貼上/刪除/全選/撤銷/重做/對齊/群組/鎖定) 雙路徑可用 (FR-1.1)。
5. 撤銷/重做歷史擴大且跨畫面持續；還原後不清除使用者操作上下文 (FR-1.5)。
6. 屬性編輯器採用分組與預設值，常用屬性優先顯示 (FR-2.4)。
7. (R) 若使用者試圖設定超出 16 層巢狀限制的巢狀元件/對話盒，給出清楚層級提示並拒絕超限操作 (FR-3.4 對應)。
8. (F) 每一編輯動作立即給出成功/失敗回饋；無靜默失敗。

### F2 元件庫選取與屬性編輯 (Component Library) — FR-2.1 ~ FR-2.4

1. 開啟元件庫 → 預設顯示「最近使用元件」與「快速放置面板」 (FR-2.3)。
2. 瀏覽元件時顯示「視覺預覽」與「常用／收藏」分類 (FR-2.1)，減少選錯元件。
3. 搜尋支援名稱、類別、功能關鍵字與中文別名 (FR-2.2)。
4. 選取元件後拖放至畫布 (接 F1) 或直接「快速放置」到畫布預設位置。
5. 開啟元件屬性編輯器 → 常用屬性優先顯示、分組顯示、預設值提示 (FR-2.4)。
6. (F) 屬性修改後立即在畫布預視反映；儲存狀態隨即更新為「未儲存」 (M4)。

### F3 對話盒 (Popup) 交易式設定 (Confirm/Cancel) — FR-3.1 ~ FR-3.4 (MUST)

1. 開啟對話盒 → 內部設值／增減按鈕**先暫存於本地狀態，不立即寫入變數** (FR-3.1 核心)。
2. 明確標示對話盒為模態 (背景不可操作) 或非模態 (背景可操作) (FR-3.2)。
3. 對話盒尺寸與內容依瀏覽器可用空間自動縮放，並受最小／最大尺寸限制 (FR-3.3)。
4. 使用者操作分支：
   - 點擊「確定」 → 將暫存設值寫入變數並套用 → (F)「設定已套用，變數已寫入」。
   - 點擊「取消」或關閉 → 捨絕所有暫存變更，變數不寫入 → (F)「已捨絕變更」。
5. 巢狀對話盒超過專案設定層級上限時，給出清楚層級提示 (FR-3.4)。
6. (R) 關鍵變數寫入動作視同「交易」，失敗時顯示人話錯誤與修復步驟，不靜默忽略。

### F4 儲存、版本與離線草稿復原 (Save & Version) — FR-4.1 ~ FR-4.4 (MUST)

1. 自動儲存預設開啟，閒止偵測時間可設定 (預設 2 秒)，停止編輯後快照至 SQLite (FR-4.1)。
2. 狀態列持續顯示自動儲存狀態：「已儲存 / 儲存中 / 儲存失敗 / 未儲存變更」 (M4)。
3. 離頁或瀏覽器強制終止前，若有未儲存變更 → 彈出無法忽略的對話：「有未儲存變更，是否復原離線草稿？」 (FR-4.2)。
4. 下次開啟專案 → 偵測到本機 IndexedDB 離線草稿 → 主動提醒復原，使用者可選擇復原/捨棄/比對後儲存 (FR-4.2)。
5. 版本紀錄頁面：列出版本快照；支援「版本比對 (diff)」與「標註重要版本」(FR-4.3)。
6. JSON 匯出／匯入包含專案設定與圖片；提供「備份至 SQLite 資料庫檔」一鍵操作 (FR-4.4)。
7. (R) 儲存失敗時須立即顯示錯誤與修復建議，禁止靜默；舊 schema-v1 專案無須轉換即可開啟，新專案預設新 schema 並向下相容 (FR-5.4)。

### F5 裝置連線與警報監控 (Device & Alarm) — FR-6.1 ~ FR-6.3, FR-7.1 ~ FR-7.2

1. 開啟「裝置連線設定嚮導」：設定 Modbus TCP 位址/埠、COM RTU 連接埠/鮑率/校驗 → 含連線測試按鈕 (FR-7.1)。
2. 連線測試結果立即回饋 (成功/失敗 + 人話原因)；儲存後全域狀態列顯示線上/離線燈 (FR-7.2, M6)。
3. 斷線後自動重連；狀態列顯示「重連中」，待送資料進入離線磁碟佇列 (FR-4.5, F6 接軌)。
4. 開啟「警報歷史」頁面 → 支援日期區間、裝置、等級、狀態 (發生/確認/解除) 組合篩選 (FR-6.2)；50 筆分頁，1 秒內回傳 (非功能需求)。
5. 警報歷史支援自動清除策略 (依天數或筆數) 與手動匯出 (FR-6.1)。
6. 趨勢取樣支援量程與警戒色設定，並可跨畫面監看 (FR-6.3)。
7. (R) 警報確認／解除動作需二次確認或人話回饋，避免現場操作員誤按 (M4 應用於警報)。
8. (F) 每一連線與警報動作給出成功/失敗回饋；斷線後資料新鮮度時間戳停止更新並以視覺方式顯著標示。

### F6 待送資料離線佇列與斷線續傳 (Offline Queue) — FR-4.5

1. 操作員在畫面上進行設值變更 → 若裝置線上，立即寫入並顯示送達回饋。
2. 若裝置離線 → 變更進入本機離線磁碟佇列 (IndexedDB/SQLite)，不丟失；狀態列顯示「待送 X 筆」 (M6)。
3. 離頁時明確提示未同步筆數，禁止靜默離頁 (PRD 痛點 #5)。
4. 網路恢復後自動重試與續傳 → 續傳完成後狀態列歸零，並給出「已同步 X 筆」回饋。
5. (R) 佇列滿或續傳反覆失敗時，發出警報並提示使用者手動匯出備份，避免資料無限增長未被察覺。

## 5. 導覽與資訊架構 (Navigation & IA)

### 5.1 全域導覽 (頂欄 / 側欄)

- 儀表板 / 專案列表 (M1 登陸頁，顯示最近專案與狀態)
- 畫面編輯器 (F1 畫布、元件樹、屬性編輯器)
- 元件庫 (F2 預覽/收藏/搜尋/快速放置)
- 對話盒與警報管理 (F3 交易式設定、警報歷史)
- 版本歷史與備份 (F4 diff、標註、一鍵備份)
- 裝置連線嚮導 (F5 Modbus/COM 設定、連線測試)
- 設定與風險說明 (自動儲存閒止時間、巢狀上限、免責聲明全文、匯出紀錄)

### 5.2 全域狀態列 (每頁皆顯示)

- 專案名稱與資料新鮮度時間戳 (例：資料更新於 2026-11-26 14:02)
- 自動儲存狀態燈：已儲存 / 儲存中 / 儲存失敗 / 未儲存變更
- 裝置線上/離線燈 (斷線時顯著變紅)
- 待送資料筆數 (離線佇列)
- 未儲存變更指示 (關閉頁面前觸發 F4 第 3 步驟)

### 5.3 頁面層級

```
儀表板 / 專案列表 (登陸頁, M1)
 ├─ 專案精靈與範本匯入 (F0)
 ├─ 畫面編輯器 (F1)
 │    ├─ 元件導覽 / 元件樹 (FR-1.4)
 │    ├─ 元件庫 (F2)
```

## 7. 互動規範與風險節點 (承接 Don Norman 體驗設計原則)

1. **可見性**：自動儲存狀態、裝置線上/離線、待送筆數、未儲存變更、資料新鮮度時間戳，隨時可見；禁止任何靜默失敗。
2. **即時回饋**：每一使用者操作 (新增元件、對齊、開啟 Popup、儲存、連線測試) 立即給出成功/失敗回饋。
3. **對應**：控制元件與結果有清晰對應；對話盒設值與變數寫入具「交易」邊界 (確定才寫入)。
4. **約束**：禁止設定超過 16 層巢狀；裝置位址/鮑率等輸入即時驗證，禁止無效組合；代號與變數名稱防止重複衝突。
5. **錯誤預防與復原**：關鍵動作 (確定寫入變數、刪除元件、版本還原) 二次確認；錯誤訊息用人話說明並給出修復步驟；提供撤銷/重做與離線草稿復原。
6. **一致性**：術語與按鈕用語 (確定/取消/套用/捨棄) 全應用一致，降低認知負荷。
7. **風險揭露可見性**：未儲存變更警告、斷線提示、免責聲明置於首屏與關鍵卡片，不可隱藏或縮小為微字。
8. **風險節點為前置條件**：離線草稿復原、對話盒交易確認、斷線待送提示，須在使用者可能造成資料遺失前主動介入，而非事後補救。
