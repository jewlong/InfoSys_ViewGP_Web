## 2. 核心風險

### 風險 A：無登入/存取控制對外部署的安全風險

- 說明：HMI 規劃器與執行階段若直接暴露於公網或廠區網路，缺乏身分驗證與授權，可能導致未授權變更畫面、讀寫 PLC 設備、竊取感測資料。
- 影響：設備被惡意操控、生產中斷、感測資料外洩。
- 緩減：MVP 預設僅供離線或內部網路使用；對外部署前必須補上登入、HTTPS、角色存取控制 (AIS-46 P0)；產品說明書明確標示「僅限內部網路，不可直接暴露於公網」。
- 殘餘風險：內部網路仍可能存在橫向移動威脅，需配合客戶網路隔離。

### 風險 B：Pi Zero 裸機可靠性邊界

- 說明：Raspberry Pi Zero W / Zero 2 W (~$10~15 美元) 為消費級單板電腦，執行 µC/OS-II + LVGL 9.4 裸機，無工業級看門狗、冗餘供電或溫度規範，長時間連續運行可能發生當機、記憶體洩漏、SD 卡損壞。
- 影響：監控終端黑畫面、警報不顯示、生產可視性暫時喪失。
- 緩減：產品定位為「監控輔助終端」而非「生產控制終端」，不直接驅動關鍵設備動作；建議定期重啟與 SD 卡備援；文件說明可靠性邊界。
- 不承諾：不保證 24×7 不停機，不提供生產 SLA。

### 風險 C：Modbus 通訊中斷行為

- 說明：Modbus TCP / COM RTU 與 PLC 的連線可能因網路斷線、設備重啟或訊號干擾而中斷；警報引擎依賴即時讀數。
- 影響：讀數停止更新、警報誤漏報、操作員誤判設備狀態。
- 緩減：後端實作連線重試與斷線偵測；畫面在通訊中斷時顯示「連線中斷」狀態並停止寫入；警報在通訊中斷時降級為「資料過期」，不繼續顯示最後值；警報歷史記錄中斷時段。

### 風險 D：產品層級風險揭露與 SLA 預期不符

- 說明：超低成本嵌入式 HMI 避免與企業 SCADA 正面競爭，但使用者可能誤將其當成全廠監控系統並期待 SLA。
- 影響：品牌風險、法律責任、客戶糾紛。
- 緩減：明確「不做」清單 (大型 SCADA、SLA 保證)；合約與文件載明「僅供參考，不承諾設備正常運行 / 生產 SLA / 零停機」；警報僅為輔助資訊，不得作為唯一安全聯鎖依據。

---

## 3. Pre-Mortem 失敗情境推演

假設上線三個月後產品被迫下架或遭重大客戶投訴，最可能原因：

1. 終端被直接暴露於公網，遭未授權存取導致設備異動 → **安全風險未控制** (風險 A)。
2. Pi Zero 長期運行當機，警報未顯示，客戶認為系統不可靠 → **可靠性邊界未揭露** (風險 B)。
3. Modbus 斷線後畫面仍顯示舊值，操作員誤判 → **斷線行為未處理** (風險 C)。
4. 客戶期待全廠 SCADA 功能與 SLA，與產品定位不符 → **商業預期未對齊** (風險 D)。

---

## 4. 風險揭露位置與建議措辭

建議在下列位置明確揭露：

- **產品官網 / 使用說明書：** 「本產品為輕量嵌入式 HMI 規劃與監控輔助工具，僅限內部網路部署，不可直接連接公網；不提供生產 SLA，亦不承諾設備正常運行或零停機；警報僅為輔助資訊，不得作為唯一安全聯鎖依據。」
- **訂閱條款 (Phase 2)：** 排除生產停機賠償與設備損壞責任。
- **PRD (AIS-46)：** 將「登入/HTTPS/存取控制」列為 P0，並在對外部署前完成；將「不承諾 SLA」列入不做清單。

---

## 5. 結論

本產品可在「小型設備廠商 / 系統整合商」的受控內部網路環境中安全使用，前提是：
1. 完成登入 / HTTPS / 存取控制 (AIS-46 P0)；
2. 清楚揭露 Pi Zero 可靠性邊界與 Modbus 中斷行為；
3. 不承諾任何生產 SLA。

建議 AIS-46 PRD 將上述安全與可靠性要求納入 MVP 驗收標準，再進行對外部署。
